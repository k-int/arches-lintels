# Arches Lintels

A lintel is a crucial load-bearing beam placed above (often Arched) doors or windows. Their purpose is to support load for the structure above. Arches Lintels aims to achieve the same: supporting an implementation of Arches on Windows.

Arches Lintels offers to help interested individuals or organisations experiment and get a feel of Arches before committing to deploying the platform in production. It helps to lower the barrier to entry, reducing the technical knowledge and experience required.

The audience for Arches Lintels is less technically skilled individuals. Arches has a rather complicated installation process, consisting of many components and key stages, and can take a great amount of time,especially when battling through error messages and environment specific issues.
